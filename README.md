# Puedo Rodar — mapas offline

Tiles vectoriales (PMTiles) por comunidad para el mapa base **sin conexión** de la
app Puedo Rodar. Los ficheros se publican como *assets* de la release
[`offline-maps`](../../releases/tag/offline-maps). Generados con `pmtiles extract`
desde el build de Protomaps. No contiene código.
